OreIQ PRD

Source-cited AI due diligence for junior mining stocks.

OreIQ helps retail and specialist resource investors turn technical reports, filings, drill results, and market context into clear mining risk reports with evidence, red flags, confidence levels, and next-step catalysts.

01

Objective

Validate whether investors will pay for mining-specific, source-cited due-diligence reports before building the full SaaS backend.

02

Primary user

Retail and semi-professional resource investors who need a disciplined first pass before spending hours reading filings, PDFs, forums, and presentations.

03

MVP scope

Company intake, source collection, deterministic report generation, mining scorecard, hype-risk snapshot, watchlist storage, Markdown export, and print output.

04

Report output

Each report separates facts, inference, missing information, red flags, catalysts, and confidence so the user can see what is proven and what still needs work.

05

Product guardrail

OreIQ should not present direct buy or sell calls. It should help users decide whether a company deserves deeper research.

06

Next backend phase

Add auth, saved reports, server-side PDF extraction, OpenAI-backed report generation, Firecrawl or Apify source collection, Stripe checkout, and alert jobs.

Core requirements
  • Company intake for ticker, exchange, commodity, project stage, jurisdiction, and market cap.
  • Source queue for URLs, pasted source text, and uploaded text or PDF references.
  • Mining-specific scorecard for project quality, dilution risk, management risk, jurisdiction risk, catalyst strength, hype risk, and confidence.
  • Watchlist and saved reports stored locally for the static MVP.
  • Exportable Markdown and printable report output.
